이모티콘 한 판 컷팅기

멈춰있는 이모티콘 한판 이미지를 올리면 일반 360×360 또는 미니 180×180 컷으로 잘라줘요. 잘린 컷은 드래그해서 순서를 바꾼 뒤, 제출용 개수만 저장할 수 있어요.

작업 순서

한판 종류 선택 → 가이드 다운 → 작업 → 배경 투명으로 이미지 저장 → 업로드 → 순서 배치 변경 → PNG 저장

1. 한판 종류 선택

2. 업로드 및 순서 배치 변경

한판 이미지를 업로드하면 자동으로 컷팅됩니다. 컷을 드래그앤드롭해서 원하는 순서로 바꿔주세요.

⚠️ 주의: 한판 이미지는 배경을 투명으로 저장한 PNG 파일로 업로드해주세요. 배경색이 들어가 있으면 컷팅된 PNG에도 배경색이 함께 저장될 수 있어요.
아직 불러온 이미지가 없어요.
원하는 순서를 정하고
저장 탭에서 PNG 저장 버튼을 눌러주세요.

일반 모드: 5×8 한판에서 40컷을 만들고, 현재 순서의 1~32번만 저장합니다.

3. 저장

변경된 순서대로 PNG가 다시 번호 매겨져 저장됩니다.

저장 규칙
일반 32개용은 한판을 40칸으로 보여주지만 PNG 저장에는 변경된 순서의 1~32번만 들어가요. 버릴 컷이나 후보 컷은 33~40번 자리로 보내면 저장되지 않습니다.
미니 42개용은 변경된 순서대로 42개 전체가 PNG로 저장됩니다.
